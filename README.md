# LumenX
一款轻量、高效的多线程资产探测与信息收集工具

## 功能特性
- 批量URL存活检测
- 自动获取网站标题
- IP地址反查解析
- HTTP状态码识别
- 多线程高并发扫描
- 彩色终端输出
- 异常自动处理

## 快速使用
1. 安装依赖:pip install requests
2. 准备目标,在`ip.txt`中放入需要扫描的URL，一行一个
3. 启动工具:python LumenX.py

## 项目结构
LumenX.py # 主程序
ip.txt # 扫描目标列表
README.md # 说明文档
